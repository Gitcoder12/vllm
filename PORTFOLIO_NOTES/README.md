# Portfolio Notes — vLLM Fork

## In plain language

vLLM is an open-source high-throughput engine for serving large language models through an API.

## Technical context

This repository is a fork of the upstream vLLM project. Upstream owns the core implementation, documentation, release process and contribution conventions. Local portfolio value should come from reproducible deployment/benchmark experiments and small, clearly attributed contributions—not presenting upstream systems code as original authorship.

## Repository provenance

- Fork: [vllm-project/vllm](https://github.com/vllm-project/vllm)
- Upstream documentation, licences, maintainers and nested agent instructions remain authoritative.
- This folder records local experiments and portfolio-specific notes only.
